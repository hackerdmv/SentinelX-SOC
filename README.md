# 🛡 SentinelX SOC

O **SentinelX SOC** é uma ferramenta de análise de ameaças cibernéticas desenvolvida em Python com interface web local utilizando Flask.

O projeto simula um ambiente de **Security Operations Center (SOC)**, permitindo análise de URLs, cabeçalhos de e-mail e indicadores de comprometimento (IOCs).

## 🎯 Para que serve

O SentinelX SOC auxilia na identificação e análise de possíveis ameaças, como:

- URLs suspeitas
- Tentativas de phishing
- Cabeçalhos de e-mail maliciosos
- Falhas em SPF, DKIM e DMARC
- IPs de origem suspeitos
- Campanhas recorrentes com os mesmos indicadores
- Consulta de reputação em serviços externos

---

## 🚀 Funcionalidades

- 🔍 URL Analyzer  
- 📧 Email Header Analyzer  
- 🌍 GeoIP Intelligence  
- 🧠 Integração com VirusTotal  
- 📡 Integração com Shodan  
- 🚨 IOC Register  
- 🧩 Campaign Detector  
- 📄 Relatórios em HTML e JSON  
- 🕒 Histórico de análises  
- 🛡 Monitoramento automático
