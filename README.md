# 🛡 SentinelX SOC

**SentinelX SOC** é uma ferramenta de análise de ameaças cibernéticas desenvolvida em Python com interface web local em Flask.

O objetivo do projeto é simular uma ferramenta de apoio para ambiente SOC/Blue Team, permitindo análise de URLs suspeitas, cabeçalhos de e-mail, indicadores de comprometimento e geração de relatórios.

---

## 🎯 Para que serve

O SentinelX SOC serve para auxiliar na análise inicial de possíveis ameaças digitais, como:

- URLs suspeitas
- Tentativas de phishing
- Cabeçalhos de e-mail maliciosos
- Falhas em SPF, DKIM e DMARC
- IPs de origem suspeitos
- Campanhas recorrentes usando os mesmos indicadores
- Consulta de reputação em serviços externos

---

## 🚀 Funcionalidades

- 🔍 URL Analyzer
- 📧 Email Header Analyzer
- 🧠 Threat Intelligence com VirusTotal
- 🌍 GeoIP Intelligence
- 📡 Shodan IP Intelligence
- 🚨 IOC Register
- 🧩 Campaign Detector
- 📄 Relatórios em HTML/JSON
- 🕒 Histórico das últimas análises
- 🛡 Active Defense Mode
